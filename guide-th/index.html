เปลี่ยนเครื่องดูโควตา Claude
ให้เป็นบัญชีของเรา

ตอนนี้เครื่องเล็กๆ นี้ยังแสดงโควตาของบัญชีเดิมอยู่ ทำตามขั้นตอนข้างล่างทีละข้อ แล้วเครื่องจะแสดงโควตา Claude ของเราแทน ไม่ต้องรู้เรื่องโปรแกรมหรือบอร์ดอะไรเลย

ใช้เวลาประมาณ 15 นาที · ทำครั้งเดียวจบ
⊡ ตัวเครื่องเสียบสายชาร์จไว้ด้วยจะดีที่สุด
⌘ เครื่อง Mac ของเราที่มี Claude Code อยู่แล้ว
≋ ชื่อและรหัส WiFi บ้านต้องเป็น WiFi แบบ 2.4 GHz (ดูขั้นตอนที่ 4)
✎ กระดาษกับปากกาไว้จดรหัส PIN 4 ตัวที่จะตั้งเอง
  • ขั้นตอนที่ 1หาว่าปุ่มไหนคือ A, B
  • ขั้นตอนที่ 2สร้างรหัส token บน Mac
  • ขั้นตอนที่ 3ล้างข้อมูลเก่าในเครื่อง
  • ขั้นตอนที่ 4ให้ Mac ต่อ WiFi ของเครื่อง แล้วกรอกข้อมูล
  • ขั้นตอนที่ 5ใส่ PIN บนเครื่อง
  • ขั้นตอนที่ 6อ่านหน้าจอ
1

รู้จักปุ่มบนเครื่อง

ที่ตัวเครื่อง

บนตัวเครื่องมีปุ่มเล็กๆ 3 ปุ่ม ในคู่มือนี้จะเรียกว่า A B และ RST (ปุ่มเริ่มเครื่องใหม่) ไม่มีใครจำได้ว่าปุ่มไหนเป็นปุ่มไหน เลยต้องลองกดดูก่อน ลองกดได้เลย ไม่มีอะไรเสีย เพราะเดี๋ยวเราจะล้างข้อมูลในเครื่องอยู่แล้ว

วิธีทดสอบ: กดทีละปุ่ม แล้วดูว่าหน้าจอเปลี่ยนยังไง

ถ้าหน้าจอมืดอยู่ ให้กดปุ่มไหนก็ได้ 1 ครั้งก่อนเพื่อปลุกจอ (กดครั้งแรกแค่ปลุกจอ ยังไม่ทำอะไร) จากนั้นกดทีละปุ่ม:

หน้าจอดับไปแล้วเริ่มใหม่ ขึ้นคำว่า Claude Usage กับแถบโหลดปุ่มนี้คือ RST
ถ้าจอขึ้น UNLOCK PIN: ตัวเลขในช่องเพิ่มขึ้น 1
ถ้าจอขึ้นกราฟ/ตัวเลข: หน้าจอเปลี่ยนเป็นหน้าอื่น		ปุ่มนี้คือ A
ถ้าจอขึ้น UNLOCK PIN: กรอบส้มเลื่อนไปช่องถัดไป
ถ้าจอขึ้นกราฟ/ตัวเลข: จอสว่างขึ้นหรือมืดลง		ปุ่มนี้คือ B
✓ เคล็ดลับติดสติกเกอร์เล็กๆ เขียน A, B, R ไว้ข้างปุ่ม จะได้ไม่ต้องจำ ขั้นตอนต่อไปต้องใช้ทุกปุ่ม

สร้างรหัส token บน Mac

ที่ Mac (ต้องมีอินเทอร์เน็ต)

token คือรหัสยาวๆ ที่บอกเครื่องว่า "นี่คือบัญชี Claude ของเรา" เราสร้างมันเองได้จาก Claude Code บน Mac

  1. เปิดแอป Terminal: กด ⌘ + Space พิมพ์คำว่า Terminal แล้วกด ↩ Enter
  2. พิมพ์คำสั่งนี้ (หรือคัดลอกไปวาง) แล้วกด ↩ Enter
    claude setup-token
  3. เว็บเบราว์เซอร์จะเปิดขึ้นมาเอง ล็อกอินด้วยบัญชี Claude ของเรา แล้วกดปุ่มอนุญาต (Authorize)
  4. กลับมาที่หน้าต่าง Terminal จะเห็นรหัสยาวๆ ที่ขึ้นต้นด้วย sk-ant-oat01-
  5. ลากเมาส์คลุมรหัสตั้งแต่ sk-ant จนถึงตัวสุดท้าย แล้วกด ⌘ + C เพื่อคัดลอก
! ยังไม่ต้องปิด Terminalเปิดหน้าต่างนี้ทิ้งไว้ก่อน ขั้นตอนที่ 4 ต้องกลับมาคัดลอกรหัสนี้อีกครั้ง
✕ รหัสนี้เหมือนรหัสผ่านใครได้ไปก็ใช้โควตา Claude ของเราได้ อย่าส่งให้ใคร อย่าแคปหน้าจอแชร์ และอย่าวางลงในแชท
? ถ้า Terminal ขอให้ "วางโค้ด" (paste code)ให้คัดลอกโค้ดที่หน้าเว็บแสดง มาวางใน Terminal แล้วกด Enter

ให้ Mac ต่อ WiFi ของเครื่อง แล้วกรอกข้อมูล

ที่ Mac + ดูหน้าจอเครื่อง

ตอนนี้เครื่องปล่อย WiFi ของตัวเองออกมา เราจะให้ Mac ต่อเข้า WiFi นั้น เพื่อเปิดหน้าตั้งค่า

4.1 ดูชื่อและรหัส WiFi จากหน้าจอเครื่อง

4.2 ให้ Mac ต่อ WiFi ของเครื่อง

  1. คลิกไอคอน WiFi ที่มุมขวาบนของจอ Mac
  2. เลือกชื่อ ClaudeMonitor-.... ให้ตรงกับที่เห็นบนเครื่อง
  3. ใส่รหัสจากหน้าจอเครื่อง แล้วกด Join
✓ ปกติMac จะบอกว่า "ไม่มีอินเทอร์เน็ต" ไม่เป็นไร เพราะ WiFi นี้มีไว้คุยกับเครื่องเท่านั้น

4.3 เปิดหน้าตั้งค่า แล้วกรอกข้อมูล

เปิด Safari แล้วพิมพ์ 192.168.4.1 ที่ช่องที่อยู่เว็บ แล้วกด Enter (บางที Mac จะเด้งหน้านี้ขึ้นมาเองในหน้าต่างเล็กๆ ก็กรอกในนั้นได้เลย)

  • 1SSID = ชื่อ WiFi บ้าน พิมพ์ให้ตรงทุกตัว ตัวพิมพ์เล็ก-ใหญ่ต้องตรงด้วย ถ้าบ้านมี 2 ชื่อ เช่น บ้าน กับ บ้าน-5G ให้ใช้ชื่อที่ไม่มี 5G
  • 2Password = รหัส WiFi บ้าน
  • 3OAuth Token = กลับไปที่ Terminal คัดลอกรหัส sk-ant-oat01-... จากขั้นตอนที่ 2 แล้วกด ⌘ + V วางในช่องนี้ (จะเห็นเป็นจุดๆ เป็นเรื่องปกติ)
  • 4Encryption PIN = ตั้งเลข 4 ตัวเองเลย เช่น 2580 จดลงกระดาษทันที ต้องใช้ทุกครั้งที่เปิดเครื่อง ถ้าลืมต้องเริ่มใหม่หมด
  • 5ส่วนที่เหลือไม่ต้องแก้ ปล่อยไว้แบบเดิม
  • 6กดปุ่ม Save & Reboot Device ถ้าขึ้นข้อความสีเขียว แปลว่าเรียบร้อย เครื่องจะเริ่มใหม่เอง
! อย่าลืมเปลี่ยน WiFi ของ Mac กลับคลิกไอคอน WiFi แล้วเลือก WiFi บ้านเหมือนเดิม ไม่งั้น Mac จะไม่มีอินเทอร์เน็ต จากนั้นปิดหน้าต่าง Terminal ได้แล้ว

ถ้ามีปัญหา

จอขึ้น WIFI FAILED

เครื่องต่อ WiFi บ้านไม่ได้ ส่วนมากเพราะพิมพ์ชื่อหรือรหัสผิด หรือเลือก WiFi แบบ 5G เครื่องจะเปิดหน้า SETUP MODE ให้เอง ทำขั้นตอนที่ 4 ใหม่ แต่รอบนี้หน้าเว็บจะถามแค่ชื่อและรหัส WiFi (ชื่อหน้าว่า Change WiFi) token กับ PIN ยังอยู่ ไม่ต้องใส่ใหม่

Mac หาชื่อ ClaudeMonitor ไม่เจอ

ดูว่าจอเครื่องยังขึ้น SETUP MODE อยู่ไหม แล้วรอสัก 10 วินาที ลองปิดแล้วเปิด WiFi บน Mac ใหม่ ชื่อจะเปลี่ยนทุกครั้งที่เครื่องเริ่มใหม่ ให้ดูชื่อจากจอเครื่องเสมอ

พิมพ์ 192.168.4.1 แล้วหน้าเว็บไม่ขึ้น

Mac อาจเด้งกลับไปต่อ WiFi บ้านเอง เพราะ WiFi ของเครื่องไม่มีอินเทอร์เน็ต ให้คลิกไอคอน WiFi แล้วดูว่ายังต่อ ClaudeMonitor-.... อยู่ไหม ถ้าไม่ใช่ ให้เลือกใหม่ ลองพิมพ์เต็มๆ ว่า http://192.168.4.1

จอขึ้น ERROR ค้างนานเกิน 5 นาที

ถ้า WiFi ต่อได้แต่ขึ้น ERROR ตลอด แปลว่ารหัส token อาจคัดลอกมาไม่ครบ ให้ทำใหม่ตั้งแต่ขั้นตอนที่ 2 (สร้าง token ใหม่) แล้วขั้นตอนที่ 3 (ล้างเครื่อง) ต่อเลย

ลืม PIN

ไม่มีทางกู้ได้ ต้องเริ่มใหม่ตั้งแต่ขั้นตอนที่ 2 สร้าง token ใหม่ ล้างเครื่อง แล้วตั้ง PIN ใหม่

ใส่ PIN ผิดครบ 10 ครั้ง

เครื่องจะลบข้อมูลทั้งหมดเองแล้วขึ้น SETUP MODE ข้ามขั้นตอนที่ 3 ไปเริ่มขั้นตอนที่ 4 ได้เลย ถ้าปิด Terminal ไปแล้ว ให้ทำขั้นตอนที่ 2 ก่อนเพื่อสร้าง token ใหม่

ผ่านไป 1 ปี ตัวเลขไม่ขึ้นแล้ว

token ใช้ได้ 1 ปี พอหมดอายุให้ทำตามคู่มือนี้ใหม่ทั้งหมดตั้งแต่ขั้นตอนที่ 2
